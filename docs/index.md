# Dinatos

Dinatos is a self-hosted workout tracker: exercises, routines, and the
activities you log against them. It is inspired by Hevy and built to run on
your own homelab.

Pick the part that matches why you are here:

- **[Using Dinatos](user-guide/index.md)**: log workouts, track
  measurements, import your history from Hevy or Intervals.icu.
- **[Running your own instance](deploy/index.md)**: self-host with Docker
  Compose, configure, upgrade, back up, set up networking.
- **Contributing**: change the code. Start with the
  [development guide](development/index.md), then read the
  [architecture](architecture/index.md) for the domain model and design
  decisions.
