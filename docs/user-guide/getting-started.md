# Getting started

This page shows how to connect the app to a Dinatos instance, get an account, and stay signed in.

## 1. Connect the app to your instance

Dinatos has no central server. The app must know which instance to use, for example `https://dinatos.example.com`.

1. Open the app.
2. On the login screen, enter the address in **Server URL**.
3. Register or log in.

The app saves the address on your device. To change it, open **Settings**. If you open the instance directly in a browser, you do not need a Server URL.

If the instance uses a self-signed certificate, the app refuses to connect. To allow it, turn on **Allow self-signed certificates** in **Settings**. This option is only in the Android and Linux apps.

> [!WARNING]
> This option turns off certificate checks for that server. Use it only on a network that you control.

## 2. Get an account

Use one of these methods:

- Ask the operator for an email and password.
- Tap **Register** on the login screen.

The first account on a new instance becomes the administrator. If an administrator or the operator turned off registration, the app hides the **Register** link. In this case, an administrator must create your account.

## 3. Take the first-run tour

When you sign in for the first time, a short tour starts. The tour dims the screen, except for the next button to press. It shows you how to choose units, save a routine and log a workout. You press the real buttons.

- **Skip step** and **Skip tour** are always available.
- The app offers the tour once for each account.
- To see the tour again, open **Settings -> Take the tour again**.
